How it works

1 Share Share your Google Sheet as Editor with Stor's account. No sheet yet? Create one: it can start empty.
2 Create Paste the sheet's link and pick an address. Stor adds the tabs your sheet lacks: Catalog with sample products, Branding, Payments, History and Stats.
3 Connect payments In Payroof Wallet: Project → Stores → Connect store. Paste its URL (your payment server) and KEY (creates a payment address per order, can't move funds) into the Payments tab. Stor then lists your tokens in a Tokens tab.
4 Allow access Google asks once to let the Tokens tab fetch USD rates from CoinGecko: click Allow access.
5 Sell Edit everything in the sheet. Paid orders appear in History. The address and the sheet stay linked for good.

Make the tabs yourself

Download the tables Stor would add and import each in Google Sheets: File → Import → Upload → Insert new sheet. Stor knows tabs by their header row and adds only the ones still missing.

1 Catalog.csv Products, prices, stock and delivery: 32 samples to edit or delete 2 Tokens.csv Header only: Stor lists your payment server's tokens in it 3 Branding.csv The store's name, description, website and style 4 Payments.csv URL and KEY from Payroof Wallet. Stor writes STATUS 5 History.csv Empty: Stor adds a row for every paid order
